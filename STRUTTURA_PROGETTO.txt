================================================================================
                         ARTAROUND - STRUTTURA PROGETTO
================================================================================

Artaround è un monorepo che contiene tre applicazioni principali e un package
condiviso per la gestione di contenuti museali, visite guidate e opere d'arte.

CONCETTI PRINCIPALI DEL DOMINIO
================================================================================

MUSEUM (Museo)
- Entità centrale che rappresenta un museo fisico
- Identificato da Wikidata ID
- Contiene floor (piani) con mappe SVG e marker

ARTWORK (Opera d'Arte)
- Oggetto fisico nel museo (dipinto, scultura, ecc.)
- Collegato a un museo tramite museumId
- Identificato da Wikidata ID
- Contiene metadati: autore, anno, dimensioni, materiali

ITEM (Contenuto)
- Contenuto digitale associato a un'opera o museo
- Può essere testo, audio, link esterno
- Ha caratteristiche: durata, livello linguistico, licenza

VISIT (Visita Guidata)
- Percorso ordinato di tappe (VisitStep)
- Ogni tappa può essere: opera, contenuto, informazione logistica
- Destinato a un pubblico target specifico

USER (Utente)
- Ruoli: admin, curator, creator, user
- Admin: gestione completa
- Curator: gestione museo assegnato
- Creator: creazione contenuti
- User: fruizione contenuti


================================================================================
WORKFLOW DI SVILUPPO
================================================================================

1. Installazione dipendenze:
   npm install

2. Avvio sviluppo (tutti i servizi):
   npm run dev

3. Build produzione:
   npm run build

4. Singole app:
   npm run dev --workspace=apps/marketplace
   npm run dev --workspace=apps/navigator
   npm run dev --workspace=apps/server

5. Build singolo workspace:
   npm run build --workspace=apps/marketplace
